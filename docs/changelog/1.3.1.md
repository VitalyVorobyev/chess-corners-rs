# 1.3.1 — 2026-10-19

Maintenance release. No API or detection-output changes.

## Changed

- Dependencies refreshed to their latest releases. Python wheels are built
  against PyO3 0.30 and rust-numpy 0.30; the `ml-refiner` feature uses
  tract 0.23.9.
- `chess-corners-core` no longer depends on `log`, and the WASM package no
  longer links `web-sys`; neither was used.

## Fixed

- The workspace dependency graph no longer contains `zip` 6.0.0
  (RUSTSEC-2026-0367, RUSTSEC-2026-0368, RUSTSEC-2026-0369). It was only
  reachable from a test-only dependency of `chess-corners-ml`; no published
  crate, wheel, or npm package included it.
- Book: corrected the vcpkg status in the C++ bindings chapter, the pyramid
  description in the orientation-methods chapter, and API links in the
  orientation chapter.
