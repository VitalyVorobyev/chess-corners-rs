# 1.1.0 — 2026-07-22

## Changed

- `chess-corners` no longer enables the `image` crate's default features,
  so no image-format codecs are compiled into consumer builds. If your
  crate calls `image::open` or `ImageReader::decode`, declare the formats
  you need on your own `image` dependency — they were previously enabled
  implicitly through `chess-corners`.
- The CLI (`cli` feature) reads PNG, JPEG, TIFF, BMP, WebP and GIF.
  OpenEXR, HDR, DDS, TGA, QOI, PNM, Farbfeld and ICO inputs are no longer
  supported.
- Minimum supported Rust version is now 1.91 (was 1.88). The `simd`
  feature still requires a nightly toolchain.
- `chess-corners-ml` 0.13.0 updates its ONNX runtime. Detector output is
  unchanged.

## Security

- Removes the AVIF encoder (`ravif` -> `rav1e`) from every consumer's
  dependency graph, and with it the unmaintained `paste` crate
  (RUSTSEC-2024-0436) and the NCSA-licensed `libfuzzer-sys`.
