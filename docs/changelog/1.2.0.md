# 1.2.0 — 2026-07-23

## Added

- `Detector::detect_u8_roi` / `Detector::detect_roi` (with the `image`
  feature) detect chessboard corners within a rectangular `Roi` of a
  larger image — single-scale, both ChESS and Radon strategies — and
  return coordinates in the full-image pixel frame. `Roi` is re-exported
  at the crate root.
